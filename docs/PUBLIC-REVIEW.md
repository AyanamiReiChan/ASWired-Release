# 1.0 公开前检查

本次检查覆盖网站、主控、Agent、内嵌 Xray 修改和修改版 Komari。扫描源文件、可达 Git 对象以及最终部署包边界；使用模式扫描与 Gitleaks，人工核对命中，不将“未命中”视为绝对安全保证。

已处理：

- 将真实部署域名/IP、内部部署和验收日志从公开文件中移除；三个 ASWired 仓库建立新的初始历史。旧历史只留在受保护备份中。
- `.deployment`、数据库、环境秘密、凭据文件、私钥、构建缓存和开发工具状态不进入公开仓库。
- 保留 RFC 7748 测试向量、AWS 文档签名测试样例和输入拒绝用例；这些是公开测试数据，不是部署密钥。扫描误报已逐项核对。
- 保留当前毛玻璃动态背景和作者来源说明；移除未使用的旧预览壁纸。
- 清理 Komari 上游仓库维护自动化，避免 fork 自动合并或覆盖整合版；更新入口指向 ASWired-Release。
- 修复首次管理员设置与预配置用户名的冲突、Komari 整合版本号识别、订阅页类型错误和套餐实例入口、连续排序版本冲突。
- 保留 MIT / MPL-2.0 及对应第三方源码和许可；部署包记录精确源提交和依赖清单。

本机验证包括主控/Agent Go 测试、主控静态检查、前端类型检查与 214 个前端测试、两个网站生产构建。Linux 原生测试、跨仓协议合同、首次账户初始化、统一登录和安装器检查由本仓库 release 工作流在 amd64/arm64 执行；只有全部通过才生成可发布的 draft Release。

本文件记录检查范围和发布门槛，不表示每个代理客户端、DNS 服务商或所有生产环境组合均完成实机验收。
