# 限速规则与触发记录

v1.0.11 起，管理员从侧栏进入「限速管理」，默认查看「限速规则」，切换到「触发用户记录」查看实际处罚。页面可见时每 30 秒刷新，也可手动刷新。

## 已有规则

规则按来源分组，包含全局行为限速、套餐和用户的显式覆盖、固定下载上限，以及套餐流量用尽后的停用或限速策略。来源没有显式覆盖时沿用上层配置；页面说明继承情况，不按全部用户与服务器的组合重复展开。

缺少全局行为限速配置时，显示 v1.0.10 引入的两条均衡默认规则。已有的自定义、明确关闭及空规则保持原样；行为规则关闭不代表同来源的固定速度或额度策略也关闭。固定下载上限为 `0` 时表示不限，触发时采样速度为 `0` 时显示 `0 Mbps`。

可按来源筛选或搜索规则、套餐和用户。全局配置入口打开「设置 → 行为限速」，套餐和用户入口进入各自管理页；仅查看此页面不会写入配置。

## 实际触发用户

列表包含行为限速和流量额度处罚事件，展示用户、服务器、规则来源、触发时速度、处罚结果及时间。仅释放事件不会单独占一行，没有触发处罚的用户也不会出现在列表中。按用户、服务器或规则搜索，或按处罚状态筛选后，可分页查看结果。

「处罚期内」「已解除」「已到期」是主控保存状态和事件的判定；无法确定时显示「状态待确认」。这些状态不证明 Agent 已执行，实际下发和执行结果仍在任务页核对。流量用尽后的处理显示为「停用该套餐凭据」，不会显示成「不限」；其他套餐提供的权限不受此项停用影响。

新的行为触发事件保存规则快照，显示触发当时的阈值和条件。旧事件没有快照时明确提示未保存历史阈值，不会拿后来编辑的规则推测当时条件。时间采用浏览器所在时区。

页面读取最近至多 1,000 条触发记录，超过范围时显示提示；顶部记录数和用户数只统计这批已加载记录，不代表全部历史，也不替代完整审计导出。

## 升级影响

本次只调整网站和主控的管理查询与事件记录，不新增后台定时扫描，不修改行为规则、计费、处罚执行或 Agent 上报周期。只读接口仅允许管理员访问，普通成员和只读 API 令牌不能读取这些管理数据。

管理 Agent 与 Komari 源码沿用 v1.0.10。从 v1.0.10 升级无需更新远端 Agent；更早版本尚未完成的 IPv6 策略部署仍需按 [默认限速与代理 IPv6 策略](DEFAULT-NETWORK-POLICY.md) 操作。主控自更新不自动升级远端 Agent。
