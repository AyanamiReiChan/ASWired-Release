# 内部中转流量

v1.0.7 的“流量分析”将内部中转流量与成员用量分别展示。中转入口使用成员订阅凭据计量；落地端可能使用多个成员共用的内部账号。这一段计数应保留为节点用量，不应再次分配到成员订阅中扣费。

## 登记分类

1. 管理员打开“流量分析 → 未归属”，根据实际节点配置核对账号和链路。
2. 将确认的条目标记为内部中转，填写线路名称，可选择来源节点。
3. 在“内部中转”中查看线路、落地节点和上传/下载用量。撤销分类后，未归属历史会恢复到原来的分类。

分类严格按落地节点和账号标识匹配。相同标识出现在其他节点时不会自动分类，也不会根据 `@internal` 等后缀自动认定。已归属订阅的账号不能通过此功能改变计费。

## 统计边界

- 分类覆盖当前查询时间范围内的历史展示，不修改历史流量、倍率、成员归属或订阅额度。
- 服务器用量及管理员趋势仍统计各节点的实际计数。相同业务经过多台节点时，各段都有观测，因此跨节点总量不能当作不重复的成员用量。
- 未登记的未知账号仍保留为未归属。共用中转账号的计数不能还原成每个成员的精确占比。
- 登记后，新采样不会只因内部账号没有订阅而标记缺口；真实的核心重启、计数下降等缺口仍保留。
- 历史缺口保留，避免根据新分类掩盖此前无法判断的计数中断。

此功能只需要更新主控与网站，现有节点 Agent 无需更新。
