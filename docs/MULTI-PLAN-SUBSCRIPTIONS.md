# 多套餐绑定与合并订阅

v1.0.17 将同一用户的多个套餐实例集中展示，并支持用户选择合并订阅范围。每个套餐实例继续使用自己的凭据、账期、额度和到期时间。

## 管理员添加套餐

在“用户管理”找到用户，打开套餐管理，查看已经绑定的全部套餐实例，再添加其他套餐。已经绑定的套餐不能重复添加；续期、调整实例参数时使用原有实例入口。

添加新套餐只创建新的订阅实例，不会更换、删除或覆盖旧实例，也不会重置旧实例已用流量。用户可以同时拥有多个不同套餐，包括独立额度套餐和共享流量池套餐。

## 用户合并订阅

用户在自己的门户或订阅页面打开合并订阅，选择“全部套餐”或“指定套餐”，保存后复制所需格式的合并地址。

- 全部套餐：自动包含当前账户的全部有效套餐实例，以后新增的有效套餐也会包含在内。
- 指定套餐：仅包含保存时选中的实例；新增套餐不会自动加入，需要用户重新选择并保存。
- 旧版已经开启的合并订阅默认保持“全部套餐”，原地址继续有效。

主控只允许选择当前账户拥有的实例。下载时重新检查实例及套餐状态，已停用、过期或因额度耗尽而不可用的实例不会因合并获得额外权限。修改合并范围后，客户端需要更新订阅才能取得最新节点。

## 计费和节点归属

合并订阅只提供统一下载地址，不会把不同套餐的剩余额度变成共享池，也不会改变限速或到期时间。节点仍携带其所属订阅实例的凭据，使用哪个实例的节点，就按该实例及其套餐规则计费。

多个套餐包含相同服务器或线路时，保留对应实例的独立凭据；不能仅按服务器地址去重并把用户固定到错误的套餐额度。

本版更新网站和主控，远端 Agent 无需更新；已有账户、套餐、订阅地址和计费历史不需要迁移或重建。
